# MiitTV

## Web version / نسخة المتصفح

**https://miittv.vercel.app**

```text
https://miittv.vercel.app
```

Works in any browser on PC or phone, nothing to install. You need your own Emby server with.

تشتغل من أي متصفح على الكمبيوتر أو الجوال بدون تثبيت. تحتاج سيرفر Emby خاص فيك.

A video player for Emby server, on Android TV and Android phones and tablets.

مشغّل فيديو لسيرفر Emby، على تلفزيونات أندرويد والجوالات والتابلت.

You need your own Emby server. MiitTV plays what's on it.

تحتاج سيرفر Emby خاص فيك، والتطبيق يشغّل اللي عليه.

## Download / التحميل

**[Download the latest MiitTV.apk](https://github.com/Miitcryo/MiitTV-releases/releases/latest/download/MiitTV.apk)**

All versions: [Releases](https://github.com/Miitcryo/MiitTV-releases/releases)

## Install on Android TV / Google TV

1. Install **Downloader** (by AFTVnews) from the Play Store on your TV.
2. Open it and enter this address:
   `https://github.com/Miitcryo/MiitTV-releases/releases/latest/download/MiitTV.apk`
3. Allow Downloader to install apps when asked, then install MiitTV.
4. Sign in with your Emby server address, username and password.

## Install on a phone or tablet

1. Open the download link above in your browser.
2. Open the downloaded file and allow your browser to install apps when asked.
3. Sign in with your Emby server address, username and password.

## التثبيت على التلفزيون

1. نزّل تطبيق **Downloader** من متجر Play على التلفزيون.
2. افتحه واكتب الرابط اللي فوق.
3. اسمح له بتثبيت التطبيقات لما يطلب، وثبّت MiitTV.
4. سجّل دخولك بعنوان سيرفر Emby واسم المستخدم والباسورد.

## التثبيت على الجوال أو التابلت

1. افتح رابط التحميل اللي فوق من المتصفح.
2. افتح الملف بعد التحميل، واسمح للمتصفح بتثبيت التطبيقات لما يطلب.
3. سجّل دخولك بعنوان سيرفر Emby واسم المستخدم والباسورد.

## Updates / التحديثات

Inside the app: **Settings → Updates → Check for updates**.

داخل التطبيق: **الإعدادات ← التحديثات ← التحقق من التحديثات**.
