# MiitTV

An Android TV app for Emby — تطبيق Emby للتلفزيون

## Download / التحميل

**[Download the latest MiitTV.apk](https://github.com/Miitcryo/MiitTV-releases/releases/latest/download/MiitTV.apk)**

All versions: [Releases](https://github.com/Miitcryo/MiitTV-releases/releases)

## Install on Android TV / Google TV

1. Install **Downloader** (by AFTVnews) from the Play Store on your TV.
2. Open it and enter this address:
   `https://github.com/Miitcryo/MiitTV-releases/releases/latest/download/MiitTV.apk`
3. Allow Downloader to install apps when asked, then install MiitTV.
4. Sign in with your Emby server address, username and password.

## التثبيت على التلفزيون

1. نزّل تطبيق **Downloader** من متجر Play على التلفزيون.
2. افتحه واكتب الرابط اللي فوق.
3. اسمح له بتثبيت التطبيقات لما يطلب، وثبّت MiitTV.
4. سجّل دخولك بعنوان سيرفر Emby واسم المستخدم والباسورد.

## Updates / التحديثات

Inside the app: **Settings → Updates → Check for updates**.

داخل التطبيق: **الإعدادات ← التحديثات ← التحقق من التحديثات**.
